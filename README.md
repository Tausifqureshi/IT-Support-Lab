# IT Support Lab

Hands-on practice labs and troubleshooting documentation for IT Support (L1/L2) roles. This repository contains real command outputs, troubleshooting steps, and screenshot evidence.

- **Primary Environment:** Xubuntu Linux (Laptop)
- **Purpose:** Hands-on practice, command verification, and practical proof of IT Support skills.
