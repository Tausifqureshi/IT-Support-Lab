# IT Support Lab (L1 / L2 Practice)

Welcome to my hands-on **IT Support Practical Lab repository**. This repository is dedicated to real-world command execution, troubleshooting workflows, and verifiable screenshot evidence performed on my local setup.

> **Note:** Theoretical concepts and interview notes are documented separately in my private notes repository. This repository is strictly for **hands-on practical execution and proof of work**.

---

## Lab Environment & Specs

- **Primary OS:** Xubuntu Linux (Lightweight, XFCE desktop & Terminal)
- **Hardware Specs:** Laptop (4 GB RAM)
- **Target Roles:** L1 / L2 Desktop Support Engineer, IT Service Desk, Technical Support

## Lab Documentation Workflow

For every practical lab, the documentation follows this clean format:
1. **Command Executed:** The exact terminal command or administrative tool used.
2. **Terminal Output / Result:** The actual log or output generated by the system.
3. **Screenshot Proof:** Visual confirmation saved inside the folder's `screenshots/` directory.

As practicals are completed, individual files are populated with screenshots and status is updated here.
